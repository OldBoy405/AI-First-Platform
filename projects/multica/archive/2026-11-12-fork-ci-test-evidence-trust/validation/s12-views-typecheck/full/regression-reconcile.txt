Verdict
-------
The failures pre-exist at HEAD: reverting both S12 files still produced 6 failures.
The victim set moves between runs (2 HEAD-only, 7 change-only, 4 shared) while the
executed test count stays at 6372, so this is not a fixed set of broken assertions.
Every file that failed in Run B passes in Run C, away from 506-file parallel load.
Reasons are dominated by `Test timed out in 5000ms`. The two `rejectCreate is not a
function` TypeErrors are downstream of the same stall: create-issue.test.tsx:1097 and
:1125 declare `let rejectCreate!` and assign it only inside the promise executor of
`mockCreateIssue.mockImplementationOnce`, so it stays undefined when the component
never reaches the create call.

NOT established by this evidence: that the flake is harmless in CI, or that its rate
is unchanged. Two runs cannot measure a rate. Reported for the U4 ruling, not absorbed.
