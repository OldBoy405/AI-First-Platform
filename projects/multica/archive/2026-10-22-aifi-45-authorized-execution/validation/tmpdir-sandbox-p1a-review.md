# P1a 只创建不启动诊断草稿：独立审阅 BLOCK

`tmpdir-sandbox-p1a-draft.mjs` 是锁定状态的草稿，仅通过 `node --check`，未执行、未创建资源。独立审阅仅基于文件，不访问容器、环境、会话、数据库或网络。此前 P1 的 BLOCK 证据与一次性 nonce 保持不变。

执行版本至少须先解决并重新审阅：

1. 确认固定版本的 Podman `info` Go 模板字段名；目前 `SeccompEnabled` 的大小写可能不匹配，不能假称已验证。
2. 删除资格不能依赖 Windows 与 Podman VM 时钟严格同步；创建时间仅作为辅助证据，实际身份须由完整回执 ID、专属名称、nonce、原有集合及安全状态共同证明。
3. 对脚本和原始证据按原始字节绑定独立审阅哈希；审阅文件、intent 及执行版本需明确对应，不能以简单布尔锁代表审核通过。
4. 对既有容器避免读取完整 inspect 数据；仅获取完成后验所必需的非秘密状态，评估引擎和客户端侧的字段投影边界。不得输出、复制或搜索任何凭据。
5. 将自建容器的网络诊断按字段留存最小结果；单个不兼容字段不能吞掉全部诊断。断电和 create 回执丢失时保留未知资源，不猜测归属或自动清理。

未完成上述复审前不得解锁或运行本草稿；即使 P1a 后续安全完成，也不代表容器内隔离或旧脚本 RED 已通过。凭据事件另见 `container-inspect-credential-exposure.md`。
